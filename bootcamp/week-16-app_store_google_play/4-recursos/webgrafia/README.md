## 🛠️ Herramientas

### ASO (App Store Optimization)
- [AppFollow](https://appfollow.io/) — Análisis de keywords y reviews (freemium)
- [Sensor Tower](https://sensortower.com/) — Datos de descargas y rankings (freemium)
- [ASO World](https://www.asoworld.com/) — Herramienta de análisis de keywords gratuita
- [Character Count Online](https://www.charactercountonline.com/) — Contar caracteres para campos de tienda

### Privacy Policy
- [App Privacy Policy Generator](https://app-privacy-policy-generator.firebaseapp.com/) — Generador gratuito para apps móviles
- [PrivacyPolicies.com](https://www.privacypolicies.com/) — Generador con modo gratuito
- [Termly](https://termly.io/) — Generador con opciones avanzadas de GDPR

### Screenshots
- [Screely](https://www.screely.com/) — Mockups de screenshots gratuitos
- [AppMockUp](https://app-mockup.com/) — Plantillas de screenshots para tiendas

## 🎓 Contexto del Bootcamp

En la semana 16 del bootcamp usamos:
- `eas submit` para enviar builds a las tiendas desde la terminal
- App Store Connect API Key (`.p8`) para autenticación iOS sin 2FA
- Service Account Google Cloud (`.json`) para autenticación Android
- Tracks de Google Play: `internal` → `alpha` → `beta` → `production`
