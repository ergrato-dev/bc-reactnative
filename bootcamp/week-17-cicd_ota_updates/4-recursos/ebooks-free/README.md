# Recursos — Ebooks Gratuitos

## Libros Recomendados (Acceso Libre)

### CI/CD y DevOps

- **Continuous Delivery — Martin Fowler**
  Los principios de CD que aplican a cualquier plataforma.
  Capítulos relevantes: deployment pipeline, testing strategies.
  [https://martinfowler.com/books/continuousDelivery.html](https://martinfowler.com/books/continuousDelivery.html)

- **The DevOps Handbook — Gene Kim (extractos)**
  Fundamentos de cultura DevOps: flujo, feedback, aprendizaje continuo.
  Extractos gratuitos en IT Revolution Press.

### GitHub Actions

- **GitHub Actions in Action — Manning (Early Access)**
  Cubre workflows, reusable actions, secretos y seguridad.
  [https://www.manning.com/books/github-actions-in-action](https://www.manning.com/books/github-actions-in-action)

- **Learning GitHub Actions — O'Reilly (capítulos gratuitos)**
  Introducción práctica a workflows, sintaxis YAML y mejores prácticas.

### React Native y Expo

- **React Native Express**
  Guía web gratuita y completa de React Native moderno.
  [https://www.reactnative.express](https://www.reactnative.express)

- **Expo Docs como ebook**
  La documentación oficial de Expo tiene una estructura tipo libro.
  Se puede leer de forma secuencial desde fundamentos hasta producción.
  [https://docs.expo.dev](https://docs.expo.dev)

## Documentación Descargable (PDF)

- **GitHub Actions YAML Cheat Sheet**
  Referencia rápida de triggers, contexts, expressions y steps.
  Disponible en: [resources.github.com](https://resources.github.com)

- **EAS Build + Update Configuration Reference**
  Toda la referencia de `eas.json` y `app.json` para builds y updates.
  [https://docs.expo.dev/build-reference/eas-json/](https://docs.expo.dev/build-reference/eas-json/)
