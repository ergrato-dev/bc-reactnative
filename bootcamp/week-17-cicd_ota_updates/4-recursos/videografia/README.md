# Recursos — Videografía

## Videos Recomendados

### GitHub Actions para React Native

- **GitHub Actions Full Course — TechWorld with Nana**
  Introducción completa a GitHub Actions: triggers, jobs, steps, matrix.
  Duración: ~2 horas | Nivel: principiante-intermedio

- **React Native CI/CD with GitHub Actions — Expo YouTube**
  Tutorial oficial de Expo sobre CI/CD con EAS Build y GitHub Actions.
  Buscar en: [youtube.com/@expo](https://www.youtube.com/@expo)

### EAS Update y OTA

- **EAS Update Deep Dive — Expo**
  Explicación detallada de cómo funciona el sistema de OTA updates,
  runtimeVersion y canales.
  Buscar en: canal oficial de YouTube de Expo

- **Over-the-Air Updates in React Native — William Candillon**
  Demonstración de OTA updates en una app real con Expo.

### CI/CD Conceptual

- **What is CI/CD? — IBM Technology**
  Explicación clara de los conceptos de integración continua y despliegue continuo.
  Aplica a cualquier stack, buena introducción para el bootcamp.

- **GitHub Actions in 10 Minutes — Fireship**
  `https://www.youtube.com/watch?v=R8_veQiYBjI`
  Resumen rápido de los conceptos esenciales de GitHub Actions.
