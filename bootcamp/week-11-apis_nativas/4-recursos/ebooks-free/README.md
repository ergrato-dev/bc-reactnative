# Ebooks Gratuitos — Semana 11: APIs Nativas

## Libros Recomendados (Free / Open Access)

### React Native

- **The React Native Cookbook** (extractos gratuitos)
  - Autor: Jonathan Lebensold
  - Capítulo relevante: "Chapter 7 — Adding Native Functionality"
  - Temas: permisos, cámara, geolocalización
  - Acceso: [reactnativecookbook.com](https://reactnativecookbook.com/)

- **React Native: Up and Running** — 2ª edición (O'Reilly)
  - Autora: Bonnie Eisenman
  - Capítulo relevante: "Chapter 6 — Platform-Specific APIs"
  - Acceso: disponible en O'Reilly Learning (1 mes gratis de prueba)

### Expo y Mobile

- **Programming Mobile Applications with React Native** (notas de clase libres)
  - Universidad Johns Hopkins — Coursera (auditable gratis)
  - Módulo 4: Native APIs in Expo
  - URL: [coursera.org/learn/react-native](https://www.coursera.org/learn/react-native)

### Seguridad Móvil

- **OWASP Mobile Security Testing Guide (MSTG)** — Completamente gratuito
  - Relevante para Semana 11: "Testing Platform APIs" (Android + iOS permissions)
  - Descarga: [github.com/OWASP/owasp-mstg](https://github.com/OWASP/owasp-mstg/releases)
  - Tema relevante: cómo NO exponer datos de cámara o ubicación en storage inseguro

## Documentación como Ebook

- **Expo Documentation PDF** — Generación propia
  - Puedes generar una versión PDF de la documentación de Expo usando herramientas como [docdown](https://docdown.io/)
  - Útil para consulta offline

## Recursos Interactivos Gratuitos

- **freeCodeCamp — React Native Course**
  - Módulo de APIs nativas con ejercicios interactivos
  - URL: [freecodecamp.org/learn](https://www.freecodecamp.org/learn)

- **The Odin Project — React section** (web, para referencia de permisos conceptuales)
  - URL: [theodinproject.com](https://www.theodinproject.com/)
