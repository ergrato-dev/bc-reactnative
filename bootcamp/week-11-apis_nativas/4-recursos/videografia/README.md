# Videografía — Semana 11: APIs Nativas

## Videos Recomendados

### Cámara y Permisos

- **Expo Camera Tutorial** — Notjust.dev
  - Duración: ~30 min
  - Cubre: CameraView, useCameraPermissions, flip camera, tomar fotos
  - Buscar: `"expo camera tutorial notjust"` en YouTube

- **React Native Image Picker** — The Net Ninja
  - Duración: ~20 min
  - Cubre: launchImageLibraryAsync, launchCameraAsync, result.assets
  - Buscar: `"react native image picker expo"` en YouTube

### Ubicación

- **Expo Location & Maps Tutorial** — Notjust.dev
  - Duración: ~45 min
  - Cubre: requestForegroundPermissionsAsync, getCurrentPositionAsync, MapView
  - Buscar: `"expo location maps tutorial"` en YouTube

- **React Native GPS Location** — Code With Beto
  - Duración: ~35 min
  - Cubre: watchPositionAsync con cleanup, reverseGeocodeAsync
  - Buscar: `"react native expo location gps"` en YouTube

### Permisos y UX

- **Handling Permissions in React Native** — William Candillon
  - Duración: ~25 min
  - Cubre: flujos de permiso, canAskAgain, Linking.openSettings
  - Buscar: `"react native permissions william candillon"` en YouTube
