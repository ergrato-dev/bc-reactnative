# Ebooks Free — Semana 02

## 📚 Libros Gratuitos Recomendados

### React Native

| Título | Enlace | Relevancia |
|--------|--------|------------|
| React Native Express | https://www.reactnative.express/ | Guía interactiva completa. Sección de listas y formularios muy útil |
| The React Native Show (GitHub) | https://github.com/callstack/react-native-paper | No es un libro, pero la documentación de RN Paper cubre muchos patrones de UI |

### JavaScript / TypeScript

| Título | Enlace | Relevancia |
|--------|--------|------------|
| You Don't Know JS (YDKJS) — Async & Performance | https://github.com/getify/You-Dont-Know-JS/tree/1st-ed/async%20%26%20performance | Para entender `useMemo` y optimización |
| TypeScript Deep Dive | https://basarat.gitbook.io/typescript/ | Capítulos de tipos y generics para tipar `FlatList` correctamente |

### Diseño Mobile

| Título | Enlace | Relevancia |
|--------|--------|------------|
| Material Design Guidelines | https://m3.material.io/ | Patrones de listas, inputs y navegación |
| Apple HIG (Human Interface Guidelines) | https://developer.apple.com/design/human-interface-guidelines/ | Comportamiento de teclado, estilos nativos iOS |

---

## 💡 Nota

Todos estos recursos son gratuitos y de alta calidad. No es necesario leerlos completos — úsalos como referencia cuando necesites profundizar en un concepto específico.
