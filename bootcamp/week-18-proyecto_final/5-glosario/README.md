# Glosario — Semana 18: Proyecto Final Integrador

Términos de cierre relacionados con la entrega y evaluación del proyecto final. Para los
términos técnicos de React Native/Expo, consulta el glosario de la semana correspondiente
(navegación, estado, animaciones, etc.).

---

## A

**Auditoría técnica**
Revisión sistemática del proyecto antes de la entrega: compilación sin errores, tests en
verde, ausencia de secretos hardcodeados y warnings de New Architecture resueltos.

## D

**Deuda técnica**
Trabajo pendiente o simplificaciones aceptadas conscientemente durante el desarrollo (un
`TODO`, una validación pospuesta) que se documentan explícitamente en vez de ocultarse.

**Definition of Done**
Criterio compartido de "terminado": una feature no está lista solo porque compila, sino
cuando cumple el checklist de integración y pasa la auditoría técnica.

## M

**MVP (Minimum Viable Product)**
Versión mínima de una app que ya resuelve el problema central del dominio. El proyecto
final no necesita todas las features imaginables — necesita las esenciales, bien hechas.

## P

**Portfolio project**
Proyecto pensado para mostrarse a futuros empleadores o clientes: código limpio, README
claro, capturas reales y decisiones documentadas, no solo "funciona en mi máquina".

## W

**Walkthrough**
Recorrido guiado por el código durante la defensa oral, explicando decisiones de
arquitectura en vivo en vez de solo mostrar la app funcionando.
