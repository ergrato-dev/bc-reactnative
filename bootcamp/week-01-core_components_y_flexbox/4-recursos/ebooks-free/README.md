# Ebooks Gratuitos — Semana 01

> Libros y PDFs gratuitos relevantes para React Native y desarrollo móvil

## 📚 Libros Recomendados

### React Native

| Título | Fuente | Descripción |
| ------ | ------ | ----------- |
| React Native Express | https://www.reactnativeexpress.com | Guía interactiva online, gratuita — cubre los fundamentos con código ejecutable en el navegador |
| Fullstack React Native (extracto) | https://github.com/fullstackreact | Capítulos de muestra gratuitos del libro oficial |

### JavaScript Moderno (base necesaria)

| Título | Fuente | Descripción |
| ------ | ------ | ----------- |
| Eloquent JavaScript (3rd Ed.) | https://eloquentjavascript.net | Libro completo y gratuito en inglés — base JS sólida |
| You Don't Know JS (YDKJS) | https://github.com/getify/You-Dont-Know-JS | Serie completa en GitHub — profundiza en el lenguaje |
| JavaScript Info | https://javascript.info | Tutorial completo y moderno de JS/ES2022+ en online |

### TypeScript

| Título | Fuente | Descripción |
| ------ | ------ | ----------- |
| TypeScript Handbook | https://www.typescriptlang.org/docs/handbook/intro.html | La guía oficial de TypeScript — gratuita online |

---

> 💡 **Recomendación para esta semana**: Si tienes dudas sobre algún concepto de JavaScript moderno (destructuring, spread, optional chaining), dedica 30 minutos a JavaScript Info antes de comenzar las prácticas.
