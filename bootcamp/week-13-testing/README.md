# Semana 13 — Testing: Jest, RNTL y Maestro

> **Fase 3 — Avanzado** | Semana 13 de 18 | ⏱️ 8 horas

## 🎯 Objetivos de aprendizaje

Al finalizar esta semana, el estudiante será capaz de:

- [ ] Configurar Jest con `jest-expo` para proyectos Expo/React Native
- [ ] Escribir unit tests para funciones puras con matchers Jest
- [ ] Testear componentes React Native con React Native Testing Library (RNTL)
- [ ] Simular llamadas a API con `jest.mock()` y módulos mock
- [ ] Testear navegación e interacciones de usuario con `fireEvent` y `waitFor`
- [ ] Comprender la pirámide de testing: unit → integración → E2E con Maestro

## 📚 Requisitos previos

- Semanas 1–12 completadas
- Conceptos de React hooks (`useState`, `useEffect`) sólidos
- TypeScript básico (interfaces, tipos)
- Node.js ≥ 18 instalado localmente
